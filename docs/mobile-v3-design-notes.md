# SM-Connect Mobile V3 Design

Visual boards:

- `mobile-v3-board-1-auth-navigation.png`: Login, dashboard, auto-hide sidebar, profile popover, and notifications.
- `mobile-v3-board-2-forms-account.png`: Purchase request form, Help Desk list/form, and change password.

Navigation decisions:

- Bottom tab bar is hidden.
- Primary application navigation uses an auto-hide sidebar.
- The profile avatar is positioned at the top right.
- Notification, Help Desk, Change Password, and Logout are accessed from the profile menu.
- Enterprise remains the only active system while retaining a scalable workspace pattern.
